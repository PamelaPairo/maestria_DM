Generalidades de los GLM

Un GLM es un modelo lineal para la esperanza transformada de una variable respuesta que tiene una distribución de probabilidad de la familia exponencial. Esto permite limitar los valores de Y al rango esperado para la variable (por ejemplo valores mayores o iguales a 0 para conteos o entre 0 y 1 para proporciones). La estimación de los parámetros se hace por máxima verosimilitud e iteraciones. Son modelos lineales ya que la variable respuesta es descripta a través de una función de enlace por una combinación lineal de los predictores X.

Los 3 componentes

  • Un componente aleatorio que identifica a la variable respuesta Y y sigue una de las distribuciones de la familia exponencial.

  • Un componente o predictor lineal que identifica a un conjunto de predictoras X en una función lineal.

  • Una función de enlace, que describe cómo se relacionan el valor esperado o medio de la variable respuesta con el componente lineal. Debe restringir los valores posibles de la variable respuesta a su rango teórico.

Propongo el modelo: \[Y \sim Poisson(\mu) \] con \[ \mu_i = e^{\beta_0 + \beta_1 x_i} \] o \[\log(\mu) = \beta_0 + \beta_1X \] \[E(Y_i) = Var(Y_i) = \lambda_i = \mu_i \]

Modelo en la escala del predictor lineal

\[log(E(Y_i)) = \beta_0 + \beta_1X_i \]

Modelo en la escala de la variable respuesta

\[E(Y_i) = \mu_i = e^{\beta_0 + \beta_1X_i} \]

La funcíón glm() nos permite crear un modelo lineal generalizado. Al igual que la función lm() toma como argumentos una fórmula y los datos pero también se debe especificar el argumento family donde indicamos la distribución de probabilidades y la función link que vamos a utilizar en el modelo.

Algunos ejemplos:

  • Binomial: link=logit

  • Poisson: link=log

  • Gaussiana: link=identidad

El modelo ajustado es:

\[ \log(\mu)=\beta_0+\beta_1 x \]

donde:

  • \(\mu = E[Y|X=x]\) es la cantidad esperada de mieleros,
  • \(x\) es la cantidad de eucaliptos.

Con las estimaciones obtenidas:

\[ \log(\mu)= -0.876 + 0.114x \]

Interpretación de \(\beta_0\):

\[ \beta_0=-0.876 \]

representa el logaritmo de la cantidad media esperada de mieleros cuando \(x=0\), es decir, cuando no hay eucaliptos.

Aplicando exponencial:

\[ \mu(0)=e^{-0.876}\approx 0.42 \]

Por lo tanto, el modelo estima aproximadamente 0.42 mieleros cuando no hay eucaliptos.

Interpretación de \(\beta_1\):

\[ \beta_1=0.114 \]

Como el vínculo es logarítmico, el efecto es multiplicativo:

\[ e^{0.114}\approx 1.12 \]

Esto significa que por cada eucalipto adicional,la cantidad esperada de mieleros aumenta aproximadamente un 12%.

Supuestos

  • Independencia entre observaciones

  • Linealidad para las variables explicatorias cuantitativas a escala del predictor lineal.

  • Ausencia de sub o sobredispersión. La varianza de la variable es mayor o menor, respectivamente, a la que se espera según la distribucion de Poisson. Esto provoca estimaciones sesgadas de los errores estándar de los coeficientes de las variables explicatorias.

Recap de Regresión Logística

Odds

Cociente entre la probabilidad de éxito de un evento y la probabilidad de que no ocurra.

\(Odds = \frac{P(x)}{1-P(x)}= \frac{\text{Nro Eventos a favor}}{\text{Nro Eventos en contra}}\)

Ej. si Odds es 3 indica que por cada 4 repeticiones del evento se espera que ocurran 3 y que una no ocurra.

Odds < 1 : es mas probable que no ocurra a que si

Odds = 1 : equiprobabilidad

Odds > 1: es mas probable que el evento ocurra a que no.

En nuestro caso:

\(Odds = \frac{391/800}{409/800}= 0.9558 \approx \frac{191}{200}\)

Por cada 191 pacientes con ECV, hay 200 pacientes sin ECV.

Logit

\(Logit = \log {\frac{P(x)}{1-P(x)}}= \log Odds\)

Odds Ratio (OR)

Es una medida de magnitud de efecto. Si tenemos el siguiente modelo de regresión logística

\(\log\left(\frac{p}{1 - p}\right) = \beta_0 + \beta_1 X\)

El odds ratio asociado a la variable \(\ X\) es:

\(\text{OR} = e^{\beta_1}\)

OR = 1 No hay efecto

OR > 1 asociación positiva

OR < 1 asociación negativa

Escalas de análisis

1- Predictor lineal

2- Odds

3- Variable respuesta

Planteamos el modelo

\(P(Y=1|X)= \frac{e^{\beta_0 + \sum\limits_{j=1}^p \beta_j X_j}}{1+e^{\beta_0 + \sum\limits_{j=1}^p \beta_j X_j}}\)

Esta función acota el resultado entre 0 y 1, lo cual es mucho más adecuado para modelar una probabilidad.

Luego de hacer algunas operaciones, podemos llegar a la expresión:

\(\log {\frac{P(x)}{1-P(x)}}= \beta_0 + \sum\limits_{j=1}^p \beta_j X_j\)

Realizamos un modelo de regresión logística para predecir si el paciente tiene una ECV en función de weight y gender.

\(\log {\frac{P(x)}{1-P(x)}}= \beta_0 + \beta_1 weight + \beta_2 varón\)

Interpretación de los coeficientes del modelo

Modelo estimado

\(\log {\frac{P(x)}{1-P(x)}}= -2.71 + 0.03* weight - 0.2*varón\)

Peso

Se espera un aumento de 0.03 unidades en el log de odds por cada aumento de 1kgr en el peso (manteniendo el resto de las variables constantes). La probabilidad de contraer una ECV aumenta con el aumento de peso del paciente.

\(\ OR = e^{\beta_{weight}}= e^{0.03}= 1.03\)

Por cada aumento de 1 kgr se estima que el odds de contraer una ECV aumente 3.05%

Género

\(\ Odds_{varón} = {\frac{Prob_{ECV} /varón}{Prob_{noECV}/varón}}\)

\(\ Odds_{mujer} = {\frac{Prob_{ECV} /mujer}{Prob_{noECV}/mujer}}\)

\(\ OR = {\frac{Odds_{varón}}{Odds_{mujer}}}= e^{\beta_{género}}= e^{-0.203}\)

El odds ratio para la variable género es 0.816, lo que indica que los varones tienen un 18,37 % menos de odds de presentar una ECV que las mujeres, manteniendo constante el peso. En consecuencia, ser mujer se asocia con un riesgo mayor riesgo relativo de ECV.

Devianza

Es una medida de la falta de ajuste del modelo. Cuanto menor es la devianza residual, mejor se ajusta el modelo.

\(\ Devianza Explicada = {\frac{Dev_{mod null} - Dev_{Mod}}{Dev_{mod null}}}\)

\(\ Devianza Explicada = {\frac{1108.71 - 1056.63}{1108.71}}= 0.046\)

Gráfico de Hosmer Lemeshow

Los gráficos de residuos vs predichos no son informativos para evaluar el ajuste del modelo, ya que la variable solo toma dos valores.

  • En el eje X se observa la probabilidad predicha de contrarer una ECV.

  • En el eje Y se observa la frecuencia de clase, el cociente entre cantidad de individuos con ECV y el total de pacientes.

  • La línea punteada designa la igualdad entre probabilidad predicha y frecuencia de clase.

  • Los círculos, que se construyen de la siguiente manera:

    • Se dividen a las observaciones en bins en base a la probabilidad predicha
    • Se calcula la frecuencia de clase para cada bin
    • En base a estas dos coordenadas se ubica al círculo en el gráfico
    • El número y tamaño indican la cantidad de observaciones en dicho grupo

Aquellos círculos que se ubiquen por encima de la línea punteada indican que el modelo está subestimando la probabilidad para dichos grupos. Mientras que si los círculos se ubican por debajo el modelo está sobreestimando la probabilidad para dichos grupos.

Hosmer_Lemeshow_plot <- function(dataset, predicted_column, class_column, bins = 10,
                                 positive_value = 1, color = 'forestgreen', nudge_x = 0, nudge_y = 0.05){

  dataset <- dataset %>%
    mutate(group = cut(!!sym(predicted_column),
                       breaks = quantile(!!sym(predicted_column), probs = seq(0, 1, length.out = bins + 1)),
                       include.lowest = TRUE, labels = 1:bins))

  positive_class <- dataset %>%
    filter(!!sym(class_column) == positive_value) %>%
    group_by(group) %>%
    summarise(n_positive = n())

  HL_df <- dataset %>%
    group_by(group) %>%
    summarise(pred = mean(!!sym(predicted_column)), n_total = n()) %>%
    left_join(positive_class, by = "group") %>%
    mutate(n_positive = replace_na(n_positive, 0),
           freq = n_positive / n_total)

  ggplot(HL_df, aes(x = pred, y = freq)) +
    geom_point(aes(size = n_total), color = color) +
    geom_text(aes(label = n_total), nudge_x = nudge_x, nudge_y = nudge_y, size = 3) +
    geom_abline(intercept = 0, slope = 1, linetype = "dashed") +
    labs(title = "Hosmer-Lemeshow",
         subtitle = "Modelo final",
         x = "Probabilidad Predicha",
         y = "Frecuencia observada",
         size = "Casos") +
    theme_minimal()
}

# Generalidades de los GLM

Un GLM es un modelo lineal para la esperanza transformada de una variable respuesta que tiene una distribución de probabilidad de la familia exponencial. Esto permite limitar los valores de Y al rango esperado para la variable (por ejemplo valores mayores o iguales a 0 para conteos o entre 0 y 1 para proporciones). La estimación de los parámetros se hace por **máxima verosimilitud** e iteraciones. Son modelos lineales ya que la variable respuesta es descripta a través de una función de enlace por una combinación lineal de los predictores X.

![Imagen adaptada de la clase de GLM de Adriana Perez](glm.png){}

**Los 3 componentes**

- Un _componente aleatorio_ que identifica a la variable respuesta Y y sigue una de las distribuciones de la familia exponencial.

- Un _componente o predictor lineal_ que identifica a un conjunto de predictoras X en una función lineal.

- Una _función de enlace_, que describe cómo se relacionan el valor esperado o medio de la variable respuesta con el componente lineal. Debe restringir los valores posibles de la variable respuesta a su rango teórico.

El modelo ajustado es:

$$
\log(\mu)=\beta_0+\beta_1 x
$$

donde:

- $\mu = E[Y|X=x]$ es la cantidad esperada de mieleros,
- $x$ es la cantidad de eucaliptos.

Con las estimaciones obtenidas:

$$
\log(\mu)= -0.876 + 0.114x
$$

Interpretación de $\beta_0$:

$$
\beta_0=-0.876
$$

representa el logaritmo de la cantidad media esperada de mieleros
cuando $x=0$, es decir, cuando no hay eucaliptos.

Aplicando exponencial:

$$
\mu(0)=e^{-0.876}\approx 0.42
$$

Por lo tanto, el modelo estima aproximadamente 0.42 mieleros cuando no hay eucaliptos.

Interpretación de $\beta_1$:

$$
\beta_1=0.114
$$

Como el vínculo es logarítmico, el efecto es multiplicativo:

$$
e^{0.114}\approx 1.12
$$

Esto significa que por cada eucalipto adicional,la cantidad esperada de mieleros aumenta aproximadamente un 12%.

- Independencia entre observaciones

- Linealidad para las variables explicatorias cuantitativas a escala del predictor lineal.

## Recap de Regresión Logística

### **Odds**

Cociente entre la probabilidad de éxito de un evento y la probabilidad de que no ocurra.

$Odds = \frac{P(x)}{1-P(x)}= \frac{\text{Nro Eventos a favor}}{\text{Nro Eventos en contra}}$

Ej. si _Odds_ es 3 indica que por cada 4 repeticiones del evento se espera que ocurran 3 y que una no ocurra.

Odds < 1 : es mas probable que no ocurra a que si

Odds = 1 : equiprobabilidad

Odds > 1: es mas probable que el evento ocurra a que no.

En nuestro caso:

$Odds = \frac{391/800}{409/800}= 0.9558 \approx \frac{191}{200}$

Por cada 191 pacientes con ECV, hay 200 pacientes sin ECV.

## **Logit**

$Logit = \log {\frac{P(x)}{1-P(x)}}= \log Odds$

## **_Odds Ratio_ (OR)**

Es una medida de magnitud de efecto. Si tenemos el siguiente modelo de regresión logística


$\log\left(\frac{p}{1 - p}\right) = \beta_0 + \beta_1 X$

El odds ratio asociado a la variable $\ X$ es:

$\text{OR} = e^{\beta_1}$

OR = 1 No hay efecto

OR > 1 asociación positiva

OR < 1 asociación negativa

## Planteamos el modelo


$P(Y=1|X)= \frac{e^{\beta_0 + \sum\limits_{j=1}^p \beta_j X_j}}{1+e^{\beta_0 + \sum\limits_{j=1}^p \beta_j X_j}}$

Esta función acota el resultado entre 0 y 1, lo cual es mucho más adecuado para modelar una probabilidad.

Luego de hacer algunas operaciones, podemos llegar a la expresión:

$\log {\frac{P(x)}{1-P(x)}}= \beta_0 + \sum\limits_{j=1}^p \beta_j X_j$

### Buscando el umbral

Probamos varios puntos de corte y graficamos el accuracy, la sensibilidad o recall, la especificidad y la precisión para cada uno de ellos.

$sensitivity = recall = \frac{TP}{TP+FN}$

```{r}
prediction_metrics <- function(cutoff, predictions) {
  tab <- predictions %>% 
    mutate(predicted_class = factor(if_else(.fitted > cutoff, 1, 0), levels = c(0,1)),

    select(term, estimate) %>%
    filter(term %in% c('accuracy','sensitivity','specificity','precision')) %>%
    mutate(cutoff = cutoff)
```

### Gráfico de Hosmer Lemeshow

Los gráficos de residuos vs predichos no son informativos para evaluar el ajuste del modelo, ya que la variable solo toma dos valores.


  * En el eje X se observa la probabilidad predicha de contrarer una ECV.
  
  * En el eje Y se observa la frecuencia de clase, el cociente entre cantidad de individuos con ECV y el total de pacientes.
  
  * La línea punteada designa la igualdad entre probabilidad predicha y frecuencia de clase.
  
  * Los círculos, que se construyen de la siguiente manera:
      * Se dividen a las observaciones en bins en base a la probabilidad predicha
      * Se calcula la frecuencia de clase para cada bin
      * En base a estas dos coordenadas se ubica al círculo en el gráfico
      * El número y tamaño indican la cantidad de observaciones en dicho grupo

Aquellos **círculos que se ubiquen por encima** de la línea punteada indican que el **modelo está subestimando** la probabilidad para dichos grupos. Mientras que si los **círculos se ubican por debajo** el modelo está **sobreestimando** la probabilidad para dichos grupos.

¿Para qué valores parece existir una sobreestimación de la probabilidad? ¿Para cuáles subestimación?

```{r}
Hosmer_Lemeshow_plot <- function(dataset, predicted_column, class_column, bins = 10,
                                 positive_value = 1, color = 'forestgreen', nudge_x = 0, nudge_y = 0.05){

  dataset <- dataset %>%
    mutate(group = cut(!!sym(predicted_column),
                       breaks = quantile(!!sym(predicted_column), probs = seq(0, 1, length.out = bins + 1)),
                       include.lowest = TRUE, labels = 1:bins))

  positive_class <- dataset %>%
    filter(!!sym(class_column) == positive_value) %>%
    group_by(group) %>%
    summarise(n_positive = n())

  HL_df <- dataset %>%
    group_by(group) %>%
    summarise(pred = mean(!!sym(predicted_column)), n_total = n()) %>%
    left_join(positive_class, by = "group") %>%
    mutate(n_positive = replace_na(n_positive, 0),
           freq = n_positive / n_total)

  ggplot(HL_df, aes(x = pred, y = freq)) +
    geom_point(aes(size = n_total), color = color) +
    geom_text(aes(label = n_total), nudge_x = nudge_x, nudge_y = nudge_y, size = 3) +
    geom_abline(intercept = 0, slope = 1, linetype = "dashed") +
    labs(title = "Hosmer-Lemeshow",
         subtitle = "Modelo final",
         x = "Probabilidad Predicha",
         y = "Frecuencia observada",
         size = "Casos") +
    theme_minimal()
}
```
